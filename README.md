# 22kHz エコー録音

スピーカーからトーンを鳴らし、その反響をマイクで録音するブラウザ用の音響ツールです。録音中の波形とスペクトルをリアルタイムに表示し、撮った音はあとから増幅して聴いたり、WebM でダウンロードしたりできます。

スピーカーやマイクが高い周波数をどこまで出せる／拾えるかの確認、反響の簡単な実験などに使えます。`index.html` 1 ファイルで動きます（Web Audio API と MediaRecorder を使用）。

## 使い方

1. `index.html` をブラウザで開く
2. 周波数・音量・波形を決める
   - 周波数は 20Hz〜22kHz（スライダーか、100Hz / 440Hz / 1k / 4k / 8k / 15k / 18k / 22kHz のプリセット）
   - 波形はサイン波・矩形波・ノコギリ波・三角波
3. 「トーン開始」でスピーカーから音を出す
4. 「録音開始」を押す（初回はマイクの許可を求められます）
5. 「録音停止」で録音リストに追加されます

録音ボタンはトーンを出している間だけ押せます。

録音リストでは、録音ごとに周波数・長さ・時刻が表示され、再生・ダウンロード（`echo_22000hz_01.webm` のような名前）・削除ができます。22kHz 付近の音はそのままだと小さすぎて聞こえないことが多いので、再生音量を ×1〜×200 まで上げられるようにしています（初期値は ×100）。

## 画面

- **信号設定** — 周波数、音量、波形、プリセット。波長と周期（音速 343m/s で計算）も表示します
- **コントロール** — トーン／録音のボタン、録音時間、マイク入力レベル（dB）
- **ビジュアライザー** — 入力波形（オシロスコープ）と 0〜24kHz のスペクトル。22kHz のラインを強調しています
- **録音リスト** — 録音の再生・ダウンロード・削除

マイクはエコーキャンセル・ノイズ抑制・自動ゲイン調整をすべてオフにして取り込んでいます。これらがオンだと反響音そのものが消されてしまうためです。

## 注意

- 22kHz 付近は多くの大人には聞こえませんが、子どもやペットには聞こえることがあります。大音量・長時間の使用は避けてください。
- 内蔵スピーカーやマイクの多くは 20kHz あたりから感度が大きく落ちるので、22kHz ではほとんど出ていない／拾えていないこともあります。
- 再生ゲインを上げすぎると音割れやハウリングの原因になります。
- 録音はメモリ上にしかないので、ページを閉じると消えます。残したいものはダウンロードしてください。
- 対応コーデックやマイクの設定がどこまで効くかはブラウザによって違います。
