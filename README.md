# 22kHz エコー録音

スピーカーから指定した周波数のトーンを出しながら、その反響をマイクで録音できるブラウザ用のツールです。録音中のマイク入力は波形とスペクトルでリアルタイムに表示され、録音はあとから音量を増幅して再生したり、ファイルとして保存したりできます。

HTML ファイル 1 つで動作し、インストールやビルドは不要です。Web Audio API と MediaRecorder API を使っています。

**デモ:** https://mimish0778.github.io/echo-recorder/

## 機能

- 20Hz〜22,000Hz のトーンを出力（初期値は 22,000Hz）。出力中も周波数、音量、波形を変更できます
- 波形は SINE、SQUARE、SAWTOOTH、TRIANGLE の 4 種類
- よく使う周波数のプリセット（100Hz、440Hz、1kHz、4kHz、8kHz、15kHz、18kHz、22kHz）
- 設定した周波数の波長（音速 343m/s で計算）と周期、音域の目安を表示
- ブラウザのエコーキャンセル、ノイズ抑制、自動ゲイン調整をオフにしてマイクを録音
- マイク入力の時間波形と 0〜24kHz のスペクトル、入力レベル（dB）をリアルタイムに表示
- 録音ごとに、周波数、長さ、時刻を一覧に表示
- 再生時の音量を x1〜x200 の範囲で増幅（初期値は x100）
- 録音を WebM ファイルでダウンロード

## 使い方

1. [デモページ](https://mimish0778.github.io/echo-recorder/) を開きます。
2. 「信号設定」で周波数、音量、波形を選びます。
3. 「トーン開始」を押すと、スピーカーからトーンが出ます。
4. 「録音開始」を押します。初回はマイクの使用許可を求められます。
5. 録り終えたら「録音停止」を押します。録音が「録音リスト」に追加されます。
6. 録音リストで、再生、再生音量の調整、ダウンロード（DL）、削除ができます。

「録音開始」はトーンを出している間だけ押せます。録音中にトーンを止めることはできますが、録音を止めたあとは、もう一度トーンを開始するまで録音できません。

### ローカルで動かす

```bash
git clone https://github.com/mimish0778/echo-recorder.git
cd echo-recorder
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。マイクは HTTPS か `localhost` でしか使えないブラウザがあるため、`index.html` を直接開いて録音できない場合はこの方法を使ってください。

## 録音ファイル

- 形式: WebM（Opus に対応しているブラウザでは `audio/webm;codecs=opus`）
- ファイル名: `echo_{周波数}hz_{番号}.webm`（例: `echo_22000hz_01.webm`）
- 一覧に表示される周波数は、録音を止めた時点で設定されていた周波数です。

録音はページ内のメモリにだけ保持されます。ページを閉じたり再読み込みしたりすると消えるので、残したい録音はダウンロードしてください。

## 仕組み

- トーンは `OscillatorNode` で生成し、`GainNode` で音量を調整して出力します（音量 100% のときのゲインは 0.85）。
- マイクは `getUserMedia` で `echoCancellation`、`noiseSuppression`、`autoGainControl` をすべて `false`、サンプルレート 48kHz を指定して取得します。反響音がブラウザの処理で消されないようにするためです。
- 表示には `AnalyserNode`（FFT サイズ 4096）を使い、`requestAnimationFrame` で毎フレーム描画します。小さな音でも見えるよう、時間波形は 12 倍に拡大して表示します。入力レベルは RMS から dB を計算し、-80dB〜0dB の範囲でメーターに表示します。
- 再生時は録音を `decodeAudioData` でデコードし、`GainNode` を通して元の音量より大きく再生できるようにしています。

## 注意事項

- 22,000Hz は、多くの大人には聞こえないか、聞こえにくい高さの音です。聞こえ方には個人差があり、不快に感じる人もいます。大きな音量で長時間鳴らさないでください。周囲の人や動物にも配慮してください。
- 多くのスピーカーやマイクは 20kHz 付近から感度が大きく下がるため、高い周波数では出力や録音が弱くなることがあります。
- 出力できる上限は、ブラウザの音声処理のサンプルレートの半分です。サンプルレートが 44.1kHz の環境では、約 22,050Hz が上限になります。
- 再生音量を大きく増幅すると、音割れやハウリングの原因になります。必要な分だけ上げてください。
- 録音形式やマイクの設定がどこまで反映されるかは、ブラウザや OS によって異なります。
