# 22kHz エコー録音

スピーカーから任意の周波数のトーンを出力し、マイクでその反響（エコー）を録音・可視化・再生できる、単一HTMLファイルの音響ツールです。Web Audio API と MediaRecorder API を利用しています。

## 概要

- ファイル: `index.html`（外部ライブラリ不要、Google Fontsのみ利用）
- 音声出力用のオシレーター、マイク入力の解析、録音・再生・波形/スペクトル表示を1画面にまとめたツール
- スピーカーの周波数特性確認、簡易的な反響・距離測定の実験、マイクの録音テストなどに利用できます

## 主な機能

| 機能 | 説明 |
|---|---|
| トーン出力 | 20Hz〜22,000Hzの範囲でオシレーターを鳴らす（周波数はスライダーでリアルタイム変更可） |
| 波形選択 | SINE / SQUARE / SAWTOOTH / TRIANGLE の4種類 |
| プリセット周波数 | 100Hz・440Hz(ラ音)・1kHz・4kHz・8kHz・15kHz・18kHz・22kHzをワンタップで設定 |
| 音量調整 | 出力音量を0〜100%で調整 |
| 波長・周期表示 | 設定周波数から音速343m/sをもとに波長・周期を自動計算して表示 |
| マイク録音 | エコーキャンセル/ノイズ抑制/自動ゲイン調整をOFFにした状態でマイク音声を収録 |
| リアルタイム波形表示 | オシロスコープ風の時間領域波形をCanvasに描画 |
| リアルタイムスペクトル表示 | 0〜24kHzの周波数スペクトラムをバー表示（5k/10k/15k/20k/22kHzの目盛り、22kHzラインを強調） |
| 音量メーター | マイク入力レベルをdBで表示 |
| 録音リスト | 録音ごとに周波数・長さ・時刻を記録し、一覧表示 |
| 再生（ゲイン調整付き） | 録音を再生でき、×1〜×200の範囲で再生音量を後から増幅可能 |
| 再生プログレスバー | 再生位置を視覚的に表示 |
| ダウンロード | 録音を `.webm` 形式でファイル保存 |
| 削除 | 不要な録音をリストから削除 |

## 使い方

1. ブラウザで `index.html` を開く
2. 「信号設定」で周波数・音量・波形を設定する（プリセットボタンも利用可）
3. 「トーン開始」を押すとスピーカーからトーンが出力される
4. 「録音開始」を押す（初回はマイクのアクセス許可が必要）
5. 反響音の収録が終わったら「録音停止」
6. 「録音リスト」から再生・音量調整・ダウンロード・削除が行える

## 画面構成

- **信号設定カード**: 周波数・音量スライダー、波形選択、プリセット周波数、波長/周期/録音数の情報表示
- **コントロールカード**: トーン開始/停止ボタン、録音開始/停止ボタン、ステータス表示、録音タイマー、マイク入力レベルメーター
- **ビジュアライザーカード**: 時間領域波形（オシロスコープ）とスペクトラム表示
- **録音リストカード**: 録音済みファイルの一覧・再生・ダウンロード・削除

## 技術的なポイント

- `AudioContext` の `OscillatorNode` でトーンを生成し、`GainNode` で音量制御
- `getUserMedia` で `echoCancellation: false / noiseSuppression: false / autoGainControl: false` を指定し、反響音をそのまま収録できるようにしている
- `AnalyserNode`（FFTサイズ4096）で時間波形と周波数スペクトルを取得し、`requestAnimationFrame` でCanvasに毎フレーム描画
- 録音は `MediaRecorder`（`audio/webm;codecs=opus` を優先）を使用し、`Blob` として保持
- 再生時は録音Blobを `AudioContext.decodeAudioData` でデコードし、`GainNode` を介すことで元の録音より大きい音量（最大×200）で再生可能
- 音量メーターはRMSからdB値を算出し、-80dB〜0dBの範囲で表示

## 注意点・制限事項

- **マイクのアクセス許可が必要です。** ブラウザの設定でマイクをブロックしている場合、録音機能は使用できません。
- **22,000Hzは多くの成人の可聴域の上限に近い、またはそれを超える周波数です。** 人によっては聞こえない、あるいは不快に感じる場合があります。長時間・大音量での使用は避け、周囲の人（特に若年者や動物）への配慮をしてください。
- **スピーカー・マイクの実機性能に依存します。** 多くの内蔵スピーカー/マイクは20kHz付近から急激に感度が落ちるため、22kHz帯では出力・収録ともに減衰が大きくなる場合があります。
- **ブラウザ・OSにより挙動が異なります。** `MediaRecorder` の対応コーデックやオーディオ制約のサポート状況はブラウザによって差があります。
- **録音データはメモリ上のみに保持されます。** ページを閉じる・リロードすると録音リストは失われます（保存する場合は都度ダウンロードしてください）。
- **音量ゲインを上げすぎると音割れ・ハウリングの原因になります。** 再生音量ゲイン(×1〜×200)は必要最小限に留めてください。

## カスタマイズのヒント

- `updateInfo()` 内の音速定数 `SPEED = 343`（m/s）を変更すれば、気温補正などに対応可能
- プリセット周波数は `.preset-btn` の `data-freq` 属性を増減させることで自由に追加・変更できる
- スペクトラム表示の対象範囲（現在0〜24kHz）は `drawLoop()` 内の `maxF` を変更することで調整可能
